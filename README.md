# Unsupervised and Reinforcement Learning Practical

## Overview

This practical demonstrates two Machine Learning concepts:

* **Unsupervised Learning:** Customer segmentation using K-Means Clustering.
* **Reinforcement Learning:** Route selection using rewards.

## Objectives

* Understand customer segmentation.
* Learn the basic working of K-Means.
* Interpret customer clusters from a business perspective.
* Understand Agent, Action, Environment, and Reward.
* Understand Exploration and Exploitation.

## Tools Used

* Python
* Pandas
* Scikit-learn
* Matplotlib

## Business Applications

K-Means can help businesses group customers and create targeted marketing strategies. Reinforcement Learning can help businesses make decisions by learning from rewards and outcomes.

## Conclusion

The practical shows how different Machine Learning approaches can be applied to real-world business problems such as **customer segmentation and route optimization**.
